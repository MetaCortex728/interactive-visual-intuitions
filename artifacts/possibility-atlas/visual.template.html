Cost model and scope

Counts describe objects; Big O describes an algorithm. Enumeration costs here include writing each complete output. Auxiliary memory excludes stored outputs. Arithmetic-operation bounds assume unit-cost integers; very large exact counts have additional bit costs. Search diagrams are idealized tree budgets, not measured cube-solver performance. Fixed 3x3 state counts are constants; n, k, b and d define the scalable families.
